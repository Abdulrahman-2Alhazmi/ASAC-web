# 🌐 ASAC Web Interface

The ASAC Web Interface is the frontend of the ASAC Voice Assistant project. It provides a clean and interactive interface that allows users to communicate with the AI assistant using voice through their web browser.

The website is designed with HTML, CSS, JavaScript, and PHP, and is deployed on InfinityFree hosting.

---

## ✨ Features

- 🎤 Voice interaction through the browser
- 💬 Modern chat interface
- 🌍 Supports Arabic and English conversations
- 🤖 Connects securely to the AI backend
- 📱 Responsive and user-friendly design
- ☁️ Hosted online using InfinityFree

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- InfinityFree Hosting

---

## 📝 Project Files

The following files were customized for the ASAC project:

- **index.html** – Main webpage structure.
- **style.css** – User interface styling and theme.
- **app.js** – Voice recognition, AI communication, and speech synthesis.
- **config.php** – Stores the API configuration securely.
- **ASAC4.php** – Backend API that communicates with the AI model.
- **.htaccess** – Protects sensitive configuration files.
